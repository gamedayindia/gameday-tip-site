# Ad Banners

Drop image files here to display them in the top carousel on the site.

Supported formats: .jpg / .jpeg / .png / .gif / .webp

Files are served automatically — no restart needed.
They appear in alphabetical order, so prefix with 01_, 02_, etc. to control order.

Example:
  01_summer-promo.jpg
  02_new-game.png
  03_sponsor-ad.webp

To use Google AdSense instead, replace the #bannerWrap div in public/index.html
with your AdSense <ins class='adsbygoogle'> snippet.
